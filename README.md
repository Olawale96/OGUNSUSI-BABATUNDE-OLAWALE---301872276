# Advanced Database Systems Portfolio

## Project Overview

This repository presents a five-part practical portfolio developed for a Master's-level Advanced Database Systems course. It demonstrates the design, implementation, testing, optimisation and management of relational, document-oriented and distributed database systems.

The case study is the Metropolitan University of Nigeria Student Registration and Result Management System (MUN-SRRMS).

## Portfolio Structure

| Portfolio | Focus |
|---|---|
| Portfolio 1 | Relational database design, schema implementation, normalisation and integrity constraints using PostgreSQL |
| Portfolio 2 | SQL query processing, indexing, execution-plan analysis and performance optimisation |
| Portfolio 3 | Database transactions, isolation levels, concurrency and integrity testing |
| Portfolio 4 | MongoDB document modelling, CRUD operations, validation, indexing and aggregation |
| Portfolio 5 | Distributed databases, PostgreSQL logical replication, monitoring, backup and recovery |

## Technologies

- PostgreSQL
- MongoDB
- SQL and MongoDB Query Language
- Docker and Docker Compose
- PowerShell
- Git and GitHub

## Case Study

MUN-SRRMS represents a university information system supporting student registration, academic programmes, courses, course offerings, enrolments and examination results.

The case study provides a consistent foundation for the relational database, transaction-processing, NoSQL and distributed database activities.

## Reproducibility

Each portfolio contains its own documentation, implementation files and supporting evidence where applicable.

Consult the README and documentation within each portfolio before executing its scripts.

Portfolio 5 includes a Docker Compose environment for demonstrating PostgreSQL logical replication. Its database credentials are demonstration-only and must not be reused in production.

## Evidence

The evidence folders contain selected execution records, screenshots, query outputs, validation results and other supporting materials.

## Scope and Limitations

This is an academic demonstration environment. Database versions, configurations and implementation limitations are documented within the relevant portfolio materials. The project should not be treated as a production-ready university information system.
