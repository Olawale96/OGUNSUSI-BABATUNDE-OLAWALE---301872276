TEST 2: ROLLBACK

Commands:

VALUES ('Portfolio 3: this row must be rolled back');

Observed output:
BEGIN
INSERT 0 1
ROLLBACK

Verification:
SELECT returned zero rows for the rolled-back event.

Result: PASS
The uncommitted record was not retained.

TEST 3: SAVEPOINT

Operations performed:
1. Insert record before savepoint.
2. Create SAVEPOINT before_optional_action.
3. Insert optional record.
4. ROLLBACK TO SAVEPOINT.
5. Insert record after savepoint.
6. COMMIT.

Observed output:
BEGIN
INSERT 0 1
SAVEPOINT
INSERT 0 1
ROLLBACK
INSERT 0 1
COMMIT

Final retained records:
demo_id 1: committed transaction
demo_id 3: retained before savepoint
demo_id 5: retained after savepoint

The optional action was absent.

Result: PASS

ADDITIONAL OBSERVATION

Identity values contained gaps after rollback.
PostgreSQL identity sequences are not transactional and
are not rolled back with ordinary transaction rollback.

OVERALL RESULT:
All three transaction-control demonstrations succeeded.
